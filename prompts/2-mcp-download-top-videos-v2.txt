Crie um MCP em Node.js (JavaScript) que leia o arquivo CSV gerado anteriormente com a lista de vídeos de uma conta do Instagram. O MCP deve receber o caminho desse CSV de forma flexível, sem ficar preso a uma estrutura rígida de pastas, e a partir dele identificar a conta correspondente.

Ao ler o arquivo, ordene os vídeos pela quantidade de curtidas (coluna likes), do mais curtido para o menos curtido, ignorando a quantidade de visualizações para fins de ordenação.

A partir dessa ordem, baixe uma quantidade específica de vídeos informada pelo usuário, começando sempre pelos mais curtidos. Cada vídeo é identificado pela coluna shortcode do CSV (esse é o "ID" do vídeo) — atenção: a URL direta do arquivo de vídeo (.mp4) NÃO está no CSV, ela precisa ser resolvida online a partir do shortcode.

Para resolver e baixar os vídeos, use uma estratégia pública que não exija nenhuma autenticação (sem login, cookies ou tokens). Não use endpoints que caiam em "login wall". A abordagem que funciona é consultar o GraphQL público (web) do Instagram por shortcode e extrair o campo video_url do nó xdt_shortcode_media. Para isso:

Faça uma requisição GET para https://www.instagram.com/graphql/query passando doc_id=10015901848480474 e variables={"shortcode":"<shortcode>"} (URL-encoded).
Envie os headers de um navegador, incluindo x-ig-app-id: 936619743392459 e um User-Agent de browser.
Pegue data.xdt_shortcode_media.video_url e baixe o arquivo a partir dessa URL.
Caso ocorra algum erro de acesso ou download em qualquer vídeo, ignore-o e prossiga, baixando apenas os vídeos possíveis.

Ao baixar cada vídeo, o nome do arquivo deve ser o número da sua ordem seguido de underline e o shortcode do vídeo (o mais curtido recebe 1, o próximo 2, e assim por diante). Armazene os vídeos baixados dentro da pasta da conta referenciada pelo CSV.

Salve o MCP na pasta resources/mcps/instagram-top-videos-download e registre-o no arquivo de configuração de MCPs na raiz do projeto.

Após construir o MCP, instale as dependências do Node (execute o npm install na pasta do MCP) para que ele fique pronto para uso.

Não execute e nem teste a funcionalidade — apenas implemente o MCP; eu mesmo farei os testes.


## Orientações técnicas

- Não use login, sessão autenticada, cookies manuais, Playwright ou Puppeteer. Utilize apenas chamadas HTTP públicas via Node.js.
- Exponha uma ferramenta MCP chamada `download_top_videos`, recebendo `csvPath` (caminho do CSV) e `count` (quantidade de vídeos a baixar).
- O caminho do CSV deve ser totalmente flexível; identifique automaticamente a conta a partir da pasta onde o arquivo `lista.csv` está localizado.
- Implemente um parser próprio para CSV compatível com UTF-8, respeitando campos entre aspas, vírgulas e quebras de linha.
- Ordene os registros utilizando exclusivamente a coluna `likes` em ordem decrescente. Ignore completamente a coluna `views` para fins de ordenação.
- Ignore registros que não possuam `shortcode` válido.
- Para resolver a URL do vídeo, utilize `GET https://www.instagram.com/graphql/query` com `doc_id=10015901848480474` e `variables={"shortcode":"<shortcode>"}` (URL-encoded).
- Utilize headers de navegador, incluindo `User-Agent`, `Accept-Language`, `Referer` e `x-ig-app-id: 936619743392459`.
- Extraia a URL do vídeo a partir de `data.xdt_shortcode_media.video_url`.
- Caso a resposta não contenha `xdt_shortcode_media` ou `video_url`, registre o erro e continue com os demais vídeos.
- Faça o download diretamente da `video_url` utilizando stream, evitando carregar o arquivo inteiro em memória.
- Salve cada vídeo com o nome `<ordem>_<shortcode>.mp4`, onde a ordem corresponde à posição após a ordenação por curtidas.
- Salve todos os vídeos na mesma pasta onde está localizado o arquivo `lista.csv`.
- Crie automaticamente a pasta de destino caso ela não exista.
- Aguarde aproximadamente 800 ms entre downloads para reduzir a chance de bloqueios temporários.
- Caso ocorra erro ao resolver ou baixar qualquer vídeo, ignore apenas aquele vídeo e prossiga normalmente com os demais.
- Ao final da execução, retorne um resumo contendo a conta processada, quantidade solicitada, quantidade baixada e lista de erros ignorados.
- Utilize ES Modules (`"type": "module"`), `@modelcontextprotocol/sdk` e `zod`.
- Registre logs apenas em `stderr`; mantenha o `stdout` exclusivo para o protocolo MCP.
- Após criar o MCP, execute `npm install` na pasta do projeto para deixá-lo pronto para uso, sem executar nem testar a funcionalidade.
